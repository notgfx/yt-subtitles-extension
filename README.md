# YouTube Subtitle Summarizer

A Chrome extension that makes it easier to extract, analyze, and summarize YouTube video subtitles using AI.

### Features

- **Subtitle Extraction** — Retrieve and download subtitles from YouTube videos.
- **AI-Powered Summaries** — Generate concise, structured summaries of video content using external LLM APIs.
- **Multiple LLM Providers** — Connect to compatible AI providers using your own API keys and select available models.
- **Custom API Configuration** — Configure API endpoints, keys, and models.
- **Proxy Support** — Route API requests through configured proxies to use alternative network connections.
- **Proxy Testing** — Import and test multiple proxy servers, check their availability, and inspect connection details.
- **Settings Management** — Export and import extension settings, including API and proxy configurations.
- **Browser Integration** — Access the extension directly from YouTube without switching between applications.

### Requirements

- Google Chrome or another Chromium-based browser.
- An API key from a supported LLM provider for AI-powered summaries.
- An internet connection.

### Privacy

The extension uses user-provided API credentials and configuration. Keep your API keys private and avoid sharing exported settings files containing sensitive information.
